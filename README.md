# ShuSunGroup research website

Public website: https://shusunlab.github.io/

English research hub for ShuSunGroup at Shanghai Jiao Tong University, featuring simulation platforms, multimodal datasets, publications, and tutorials.

## Publishing and editing

GitHub Pages publishes the root of the main branch. No build or package installation is required. Edit the HTML pages for content, portal.css for the responsive design, and cover-*.svg for illustrative artwork. Cover images are labeled as illustrations. Changes committed to main are published automatically.

## Analytics

The public site currently has no configured analytics service. site-config.js contains optional public endpoint settings; no visits are recorded by this client until a service is connected. The separate backend must permit credential-free CORS from https://shusunlab.github.io while keeping its owner dashboard authenticated. No integration keys belong in public files.

Download-entry clicks are distinct from completed downloads. Actual software downloads, dataset downloads, and local or web simulation usage require reporting from those services. The illustrative scene is not a simulation run. TB-scale research data stays with its external host.

Each linked research resource retains its own licensing terms. This website does not grant a new software or dataset license.
