PRIVACY & ANALYTICS

Understanding resource usage.

We use basic activity counts to understand which research resources are useful.

Current analytics status

Optional analytics require JavaScript. Use the control below to check or change this browser’s preference.

Website hosting

This public website is hosted on GitHub Pages. GitHub may collect technical information, including IP addresses, to operate and secure its service. See GitHub’s privacy statement.

Optional research analytics

The website reports page views and research-resource link clicks to a separate analytics service hosted on Cloudflare. Reports contain an event identifier, a page path, a resource name, and a random tab-session identifier. The browser does not include URL query strings, referrer URLs, research inputs, names, or email addresses in these reports. The service receiving a request can see its network address.

The analytics service hashes tab-session identifiers with the UTC date for daily session counts. Sessions are not unique people. The analytics database does not store IP addresses or referrer URLs. Cloudflare processes network information to operate and secure its service; see Cloudflare’s privacy policy. Event records are retained until removed by the site owner. Access to stored statistics requires the owner’s Cloudflare account.

Downloads and simulation usage

A click on download instructions is different from a completed download. Actual dataset downloads, software downloads, and local or web simulation runs require reports from the corresponding download service or simulation software. These download-completion and simulation integrations are not currently connected. The website does not infer successful downloads or simulations from clicks. The illustrative scene does not report simulation runs.

Your choice

Optional browser analytics respect Do Not Track and Global Privacy Control. You can also disable them in this browser. Local simulation reporting should be enabled only with the software user’s agreement.

External resources

Dataset hosts, GitHub repositories, and video services apply their own privacy practices when you follow their links.
