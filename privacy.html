PRIVACY & ANALYTICS

Understanding resource usage.

We use basic activity counts to understand which research resources are useful.

Current analytics status

Optional research analytics are not configured for this deployment.

Website hosting

This public website is hosted on GitHub Pages. GitHub may collect technical information, including IP addresses, to operate and secure its service. See GitHub’s privacy statement.

Optional research analytics

When connected to an analytics service, the website can report page views and research-resource link clicks. Reports contain an event identifier, a page path, a resource name, and a random tab-session identifier. The browser does not include URL query strings, referrer URLs, research inputs, names, or email addresses in these reports. The service receiving a request can see its network address.

The prepared analytics service hashes tab-session identifiers with the date for daily session counts. Sessions are not unique people. Service-side retention and access settings must be configured when the service is activated.

Downloads and simulation usage

A click on download instructions is different from a completed download. Actual dataset downloads, software downloads, and local or web simulation runs require reports from the corresponding download service or simulation software. The website does not infer successful downloads or simulations from clicks. The illustrative scene does not report simulation runs.

Your choice

Optional browser analytics respect Do Not Track and Global Privacy Control. You can also disable them in this browser. Local simulation reporting should be enabled only with the software user’s agreement.

External resources

Dataset hosts, GitHub repositories, and video services apply their own privacy practices when you follow their links.
