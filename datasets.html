ACCESS THE DATA

Start with the
official instructions.

The repository provides the current SJTU Pan link and extraction code. Data files are hosted externally, separate from this website.

  1. Read the project overview

    Understand the prediction task, research context, and available materials.

  2. Follow the download instructions

    Use the repository’s Download section for the hosting link and access code.

  3. Review usage and citation

    Check applicable data terms and include the paper citation when using the research.
