Common questions

Are the cover images actual experimental results?

The PanoLAMP cover is an author-provided project figure. Other covers are labeled as illustrations, and the interactive scene is a concept illustration.

Does this website host the full dataset?

No. The PanoLAMP repository points to the external data host. Follow its current download instructions; performance depends on your network and the hosting service.

Can I run HoloChanTwin directly on this website?

The interactive scene is a browser illustration. For the actual simulation software and its supported environment, use the official HoloChanTwin repository.
